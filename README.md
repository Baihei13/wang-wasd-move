# Wang WASD Move

玩家在**非战斗**时只能用 **WASD**（以及 Foundry 自带的方向键）移动 Token；**禁止鼠标拖拽**。  
**战斗开始后**自动允许鼠标移动；战斗结束再锁回 WASD。  
GM 始终不受限制。

## 安装

1. 将文件夹 `wang-wasd-move` 放到 Foundry 的 `Data/modules/`（本地已放好）
2. 若用远程服务器：把该文件夹同步到服务器的 `Data/modules/`
3. 管理模块 → 启用 **Wang WASD Move**
4. 刷新 / 重进世界

## 使用

1. 玩家先**选中自己的 Token**
2. 探索阶段：按 `W A S D` 一格一格移动；拖拽会被拦截并提示
3. GM 开始战斗后：玩家可用鼠标正常拖拽
4. 战斗结束后：重新变为仅键盘

## 设置（世界）

| 设置 | 默认 | 说明 |
|------|------|------|
| 启用非战斗 WASD 限制 | 开 | 总开关 |
| 战斗中解除限制 | 开 | `combat.started` 后允许鼠标 |
| 拦截拖拽时提示 | 开 | 玩家被拦时通知 |
| 允许对角线 | 开 | 如 `W+D` 斜移 |
| 显示角落提示 | 开（客户端） | 左下角状态条 |

快捷键可在 Foundry「配置控制」里改绑。

## 兼容

- Foundry v13–v14
- 系统无关（PF2e 可用）
- 若已启用 `lib-wrapper` 会优先用它包装拖拽检测
